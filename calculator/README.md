# Modern Glass Calculator

A sleek, premium calculator web application built with HTML, CSS, and Vanilla JavaScript.

## Features
- ✨ **Glassmorphism Design**: Modern UI with blur effects and deep slate theme.
- 📱 **Fully Responsive**: Optimized for both mobile devices and desktops.
- ⌨️ **Keyboard Support**: Full control using your keyboard.
- 🧮 **Precision Math**: Handles basic arithmetic with decimal support and error handling.
- ⚡ **Interactive Animations**: Smooth hover and click effects.

## How to Run Locally
1. Extract the `calculator.zip` file.
2. Open the `calculator` folder.
3. Double-click `index.html` to open it in your default web browser.

## Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Modern layouts with CSS Grid and Glassmorphism.
- **JavaScript**: Modular Class-based logic (No frameworks).

## Keyboard Shortcuts
- `0-9`: Numbers
- `.`: Decimal point
- `+, -, *, /`: Operations
- `Enter` or `=`: Compute
- `Backspace`: Delete last digit
- `Esc`: Clear all
